# King Fahad National Library - Registration Website

A Flask web application for the King Fahad National Library. Visitors must register before accessing the site's pages. Registration data is stored in a SQLite database and managed through an admin panel.

## Features

- User registration with validation (name, email, address, Saudi phone number)
- Pages: Home, About, Services, Sections, Contact Us
- Admin panel to view registered users

## Tech Stack

- Python, Flask
- SQLite
- HTML, CSS, JavaScript
